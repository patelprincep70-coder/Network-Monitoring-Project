NETWORK MONITORING SYSTEM - RUN GUIDE

1. Install Node.js (LTS) on your computer.
2. Open this project folder in Visual Studio Code.
3. Open Terminal in this folder.
4. Run:
   npm install
5. Then run:
   npm start
6. Open this address in your browser:
   http://localhost:3000

IMPORTANT:
Do NOT double-click index.html to run this project.
The website uses /api endpoints, so it must be started through server.js.

Features:
- Add device with name + IPv4 address
- Prevent duplicate IP addresses
- Store devices in devices.json
- Check device Online/Offline
- Show response time
- Delete devices
- Monitor all devices
